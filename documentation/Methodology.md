# Methodology
1. Inspected all three sheets; only `July` is raw. 2. `src/preprocessing.py` checks 9 validity rules (duplicate IDs, rating range, non-positive value, negative distance, success with zero distance, non-success with distance, non-success with ratings/payment, status vs reason mismatch, Date/Time mismatch). All returned 0 violations, so no rows were removed. 3. Structural nulls are kept (not applicable, not missing-at-random). 4. Quality score = 100 x (1 - violations / (rows x 9)) = 100.00; this measures internal consistency only. 5. KPIs defined once in `src/kpi_engine.py` and mirrored in SQL and DAX. 6. SQL validated against pandas in SQLite (10 business questions match). 7. Tests used: chi-square (success vs vehicle, hourly uniformity), one-way ANOVA (rating vs vehicle), Pearson correlation.
Peak hours are derived (top quartile of hourly counts), not assumed. Weekday comparisons use per-day averages because July 2024 has five Mon/Tue/Wed and four of each other weekday.
